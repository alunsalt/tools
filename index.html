Tools

Small single-file tools for Botany One.

  • POW ScaffoldPlan page for Plant of the Week, with downloadable maps for a species and prepared searches for the web.
  • Shooting Plan BuilderPlan a video shoot in narrative order; export a phone aide, a Markdown save file, or a blog draft.

Each entry is one list item. To add a page, copy a whole <li>…</li> line, paste it on its own line inside the list, and edit the link and label.
